== March's orders: a condition on placed_at, the partition key
EXPLAIN (COSTS OFF) SELECT count(*) FROM orders_by_month
WHERE placed_at >= '2026-03-01 00:00+07' AND placed_at < '2026-04-01 00:00+07'
                                                                        QUERY PLAN                                                                        
----------------------------------------------------------------------------------------------------------------------------------------------------------
 Aggregate
   ->  Seq Scan on orders_2026_03 orders_by_month
         Filter: ((placed_at >= '2026-03-01 00:00:00+07'::timestamp with time zone) AND (placed_at < '2026-04-01 00:00:00+07'::timestamp with time zone))

== a primary key without the partition key
CREATE TABLE orders_by_month_id_only (id integer PRIMARY KEY, placed_at timestamptz NOT NULL)
PARTITION BY RANGE (placed_at)
ERROR:  unique constraint on partitioned table must include all partitioning columns
